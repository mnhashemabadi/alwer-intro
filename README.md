# آلور

آلور را خلاف تابلوی آگهی معمولی چیدم. خریدار اول نیازش را می‌نویسد و فروشنده روی همان درخواست قیمت می‌دهد. پیشنهادها کنار هم‌اند تا بشود مقایسه کرد. آگهی فروش هم روی همین بازار است و در جستجو دیده می‌شود.

سایت: [alwer.ir](https://alwer.ir)

آلور یک وب‌سایت است و یک برنامهٔ موبایل دارد.

## English

I arranged Alwer against a normal listing board. The buyer writes the need first. A seller prices that same request. Offers sit side by side so they can be compared. A sale listing is on the same market and shows up in search.

Site: [alwer.ir](https://alwer.ir)

Alwer is a website and a mobile app.
